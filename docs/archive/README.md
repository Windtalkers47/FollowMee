# Archived FollowMee session documents

เอกสารในโฟลเดอร์นี้เป็น handoff, recap, review และ validation รุ่นเก่าที่เก็บไว้
เพื่ออ้างอิงและ audit trail ไม่ใช่ source of truth สำหรับงานปัจจุบัน

ให้ใช้ [Developer Handbook](../DEVELOPER_HANDBOOK.md) ก่อนเริ่มงานใหม่ ส่วน
database/deployment runbook ที่ `database/` และ `docs/` ยังคงเป็นเอกสารปฏิบัติการ
ที่ใช้งานอยู่

## Contents

- ไฟล์ `FOLLOWMEE_SESSION_*` และ `FOLLOWMEE_PROJECT_RECAP_*`: historical session handoff
- `reviews/`: product, technical และ P1/M1 reviews ที่ถูกสรุปใน Handbook แล้ว
- `backend-validation/`: historical release/sprint validation และ remediation reports

เอกสาร archive อาจมีคำสั่งหรือ environment assumptions ที่ถูกแทนที่แล้ว ห้ามนำไปใช้
กับ production โดยไม่ตรวจ Handbook และ runbook ปัจจุบัน
